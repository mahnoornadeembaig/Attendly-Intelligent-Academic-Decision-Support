Attendly matters because it goes beyond basic attendance recording. It combines three dedicated user experiences and analytical features to turn attendance records into more useful insights.💎📉

**🔎Key Features:**
**-** Role-Based Access
**-** Separate Admin, Teacher & Student Dashboards  
**-** Student & Teacher Registration and Records  
**-** Attendance Recording & History  
**-** Add, Read, Update, Search & Delete Operations  
**-** Course-Wise Attendance Tracking  
**-** Smart Search & Date-Based Filters  
**-** Attendance Behaviour Analysis  
**-** Weekday-Wise Absence Patterns  
**-** Course-Wise Attendance Analytics  
**-** Monthly Attendance Trends  
**-** Attendance Risk Monitoring  
**-** Below-75% Attendance Alerts  
**-** Excel & PDF Report Export  

**Technologies: ** C#, Windows Forms, .NET Framework, Microsoft SQL Server
